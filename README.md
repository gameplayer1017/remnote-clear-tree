# Clear Tree

RemNote의 부모·자식 노트를 원래 위치에서 가로 트리로 보여주는 플러그인입니다. 한국어·영어 제목을 한 줄로 표시하고, 가지를 접고 펼치거나 본문으로 이동할 수 있습니다.

## 사용법

1. 문서 본문의 부모 Rem 한 줄에 커서를 놓습니다.
2. `/Inline Tree`에서 **Inline Tree · 트리 전환**을 실행합니다.
3. 자식이 있는 항목을 클릭하면 가지를 접고 펼칩니다. 더블 클릭과 구분하기 위해 약 0.2초 뒤에 반영합니다.
4. 끝 항목을 클릭하면 같은 문서에서 제목이 일치하고 내용이 있는 본문 항목을 찾아 엽니다. 가지 제목은 더블 클릭하면 이동합니다.
5. 부모 줄의 `/Inline Tree`를 다시 실행하면 원래 목록으로 돌아와 내용을 편집할 수 있습니다.

Overall Tree와 본문을 따로 작성한 문서에서도 제목이 일치하면 연결됩니다. 번호만 같고 제목이 다른 항목에는 연결하지 않습니다. 후보가 여러 개면 상위 제목과 실제 내용 유무를 비교합니다. 중분류는 Overall Tree와 같은 부모 아래의 본문 제목을 우선합니다. 그래도 중복되면 원래 항목을 엽니다.

## 설치와 배포 상태

개인용 `unlisted` 플러그인으로 RemNote 검수 제출을 준비하고 있습니다. 배포 버전은 1.0.0이며, 소스 업로드 대상은 `https://github.com/gameplayer1017/remnote-clear-tree`입니다. 저장소 생성·소스 업로드·검수 제출은 아직 완료되지 않았습니다. 검수 승인 전에는 마켓플레이스에서 설치할 수 없습니다. ZIP 업로드는 즉시 로컬 설치가 아니라 검수 제출 절차입니다.

승인 후에는 RemNote가 배포 파일을 제공하므로 사용자의 컴퓨터에서 localhost 서버를 켜둘 필요가 없습니다. 현재 개발 설치 사용자는 승인 후 배포판으로 전환해야 합니다.

- [개인용 플러그인 공식 안내](https://plugins.remnote.com/advanced/unlisted_plugins)
- [검수 제출 공식 안내](https://plugins.remnote.com/advanced/submitting_plugins)

## 권한 및 데이터 처리

플러그인은 `All / ReadCreateModify` 권한을 요청합니다. 이 권한은 지식베이스의 읽기·생성·수정을 허용합니다. 구현에서는 노트를 읽고, 전환용 power-up을 생성·부착·제거하며, 원래 목록의 접기·펼치기 상태를 변경합니다.

- 원문 내용, 부모 관계, 순서, 카드 내용은 재작성하거나 삭제하지 않습니다.
- 노트 데이터는 외부 서버, 분석 서비스, AI API로 전송하지 않습니다.
- 네트워크로 외부 콘텐츠를 가져오는 기능이나 분석 도구는 없습니다. RemNote SDK와 앱 간 통신을 사용합니다.
- 로컬 플러그인 저장소에는 전환 대상의 포털 ID를 기록합니다.
- 기존 RemTree의 CSS를 복사하거나 실행하지 않습니다. 렌더링은 공식 `UnderRemEditor` 위젯 안에서 수행합니다.
- 원래 제목을 숨기는 호스트 CSS는 표시할 부모 Rem ID로 범위를 한정하고, 위젯을 해제할 때 제거합니다.

## 제한과 복구

- 최대 1,000개 항목과 깊이 30단계까지 표시합니다.
- 본문 연결은 현재 문서의 제목 계층에서만 찾고, 후보 검사는 1,500개로 제한합니다.
- 이미지·수식·특수 서식을 원본처럼 렌더링하지 않습니다. SDK가 거부하는 서식은 일반 텍스트 또는 대체 표기로 읽고 안내를 표시합니다.
- 가로로 긴 내용은 스크롤로 봅니다. 모든 항목은 자동 줄바꿈을 하지 않습니다.
- 일반 본문 Rem을 대상으로 개발했습니다. 모바일 사용은 켜져 있으며 화면 크기 설정과 터치 동작을 보완했습니다. 표 셀, 포털, iOS·Android 실기기의 모든 동작은 검증하지 않았습니다.
- 원래 목록으로 복구할 때 부모의 직접 자식을 펼칩니다. 손자 이하의 접기 상태는 그대로 둡니다.
- 플러그인을 끈 뒤 원래 목록이 접혀 있으면 부모 글머리표에서 펼치세요. 플러그인이 적용한 CSS는 비활성화 시 앱에서 제거됩니다.

## 개발

Node.js 18 이상과 pnpm이 필요합니다.

```sh
pnpm install --frozen-lockfile
pnpm run check-types
pnpm test
pnpm run build
pnpm run dev
```

개발 설치: RemNote → Settings → Plugins → Build → Develop from localhost → `http://localhost:8080`.
개발 서버를 종료하면 개발 설치는 작동하지 않습니다. `python3 serve.py`로 빌드된 `dist/`를 제공할 수도 있습니다.

## 검수 제출 패키지

현재 로컬 서버는 macOS 로그인 시 LaunchAgent로 시작하며, 종료되면 자동 재시작합니다. 빌드와 설치 스크립트가 포함된 인계 ZIP에서는 아래 명령으로 설치 계획을 확인하거나 기존 로컬 서버를 갱신할 수 있습니다. 설치 시 실행한 Python의 절대 경로를 저장합니다. 원문 노트는 변경하지 않습니다.

```sh
python3 scripts/install-local-server.py --dry-run
# 실제 설치/갱신이 필요할 때 실행:
python3 scripts/install-local-server.py --install
```

`dist/`는 공개 저장소에서 제외되므로 저장소만 받은 경우 먼저 빌드하세요. 서버는 `127.0.0.1:8080`에서만 제공합니다. 모바일은 `enableOnMobile: true`입니다. 노트북의 localhost 개발 설치를 휴대폰에서 사용할 수 없으므로, 모바일 사용에는 RemNote 호스팅 배포가 필요합니다. iOS·Android 실기기 동작은 배포 후 확인하세요. `unlisted`는 검색 목록에서 숨기는 설정이며 접근을 본인에게만 제한하는 설정이 아닙니다.

`public/manifest.json`의 `repoUrl`을 실제 공개 소스 저장소 URL로 설정하고 `unlisted: true`를 유지하세요.

```sh
pnpm run check-types
pnpm test
pnpm run build
pnpm run package:zip
```

생성된 `PluginZip.zip`을 RemNote의 Upload plugin으로 제출합니다. 제출해도 승인 전까지 사용할 수 있는 배포판이 되지는 않습니다.

## 검증

SDK 타입 검사, 계층 순서·순환·누락·개수/깊이 한도, 긴 문장 배치, SDK 서식 오류의 대체 읽기, 제목 매칭·중복 후보 테스트를 포함합니다. 인라인 트리 표시는 실제 RemNote 데스크톱에서 확인했습니다. 본문 이동과 서식 대체 읽기의 모든 실제 문서 조합은 검증하지 않았습니다.
